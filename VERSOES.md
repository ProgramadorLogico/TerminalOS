
# Versões

### Protótipo

A versão protótipo foi a primeira e sempre será a primeira versão do TerminalOS, ela mostra mecânicas básicas, ainda sem incluir
muitas coisas relevantes, é uma versão muito importante.

### Alpha 1.0

A versão Alpha 1.0 é muito importante pois ela rescreve o código do zero e melhora frases, sem contar no Backend onde os códigos
foram melhores organizados e muitos mais limpos, sem comentários excessivos onde desnecessários.
