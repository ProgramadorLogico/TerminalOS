Forma de instalação

Nesta parte você verá como usar ou instalar o TerminalOS


O projeto TerminalOS é redirecionado a máquinas com linux instalado, mas pode ser utilizado em máquinas Windows, siga um dos passo a passo para poder instalar ou usar o TerminalOS

Opção 1: Arquivo de instalação para Linux


ATENÇÃO! Este processo só serve para máquina com Linux


Para fazer a instalação do TerminalOS via arquivo Shell Script, primeiro você deve baixar o arquivo, clique neste link abaixo para ir para o repositório oficial:


Link de download do arquivo Shell Script

Após clicar no link, você deverá ser levado a página do projeto, lá, você deve clicar no ícone de download. Logo então, um arquivo será baixado, se o navegador pedir onde salvar, escolha a pasta Downloads ou de sua preferência.
abra o gerenciador de arquivos de seu sistema Linux, navegue até a pasta onde o arquivo foi salvo, clique com o botão direito em qualquer lugar vazio da pasta, logo então, uma tela se abrirá, clique na aba onde diz "Abrir com terminal" ou então algo similar a isso. Seu terminal do Linux irá se abrir, digite o comando abaixo:

chmod +x NOME-DO-INSTALADOR.sh

Explicação: Este comando dá permissão de execução ao arquivo cujo nome foi digitado, no caso para o instalador, substitua onde diz NOME-DO-INSTALADOR.sh para o nome do arquivo de instalação real, como: instalar.sh


Apenas digite isso e aperte ENTER:

./NOME-DO-INSTALADOR.sh

Após apertar ENTER, a instalação começa, leia atentamente tudo que é escrito e sempre verifique conforme o programa explica
